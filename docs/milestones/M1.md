# M1 — World and rendering

## Scope
- `sim::TileMap`: terrain, height (0–7), groundwater, fertility, resources, roads, building occupancy, per-chunk dirty flags.
- `sim::generate_map`: seeded value-noise elevation and moisture, optional coast on any side, meandering river, terrain classification, resources.
- Art pipeline: `tools/artgen` (Python + Pillow) → `assets/sprites/**` → `tools/atlas/pack.py` → `assets/atlas/main.{png,json}`. Contact sheet at `build/contact_sheet.png`.
- Renderer (`src/render`): one instanced sprite pipeline (GLSL → SPIR-V/MSL) with depth-tested y-sorting; static chunk instance buffers rebuilt on dirty; per-frame dynamic and translucent sprite batches; far zooms (½, ¼) draw a one-texel-per-tile terrain texture; per-tile overlay texture.
- Camera: zoom levels ¼, ½, 1, 2, 3, 4 (× display density), pixel-snapped origin, WASD/arrow pan, right/middle-drag pan, wheel zoom around the cursor.
- `urbs --screenshot out.png --frames N [--zoom z] [--map-size n] [--seed s] [--cam tx ty]` for automated visual checks.

## Decisions
- **Depth-tested y-sort instead of CPU sorting.** Every sprite carries a depth derived from its foot y; pixel art alpha is binary, so depth write + discard gives correct overlap with no sorting. Translucent sprites draw afterwards without depth write.
- **Terrain transitions** use edge/corner fringe overlays by terrain priority (deep < shallow < marsh < sand < rock < grass < fertile < forest), not full 47-tile blob autotiling.
- **Atlas packer** is Python (`tools/atlas/pack.py`) rather than a C++ stb_rect_pack tool: one language for the whole art pipeline.

## Exit
- A 768² map renders at 60 FPS at every zoom on the M1 dev machine.
- The art style is locked on a contact sheet.

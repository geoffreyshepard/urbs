# M0 — Foundation

## Scope
Repo skeleton, CMake presets, pinned CPM dependencies, CI workflow, SDL3 window with an SDL_GPU clear colour, Dear ImGui debug overlay, logging, Tracy (opt-in preset), doctest, `urbs_headless` stub, clang-format/clang-tidy configs.

## Presets
- `dev`: Debug, ASan + UBSan, Ninja, `build/dev`
- `release`: Release, `build/release`
- `profile`: Release + `TRACY_ENABLE`, `build/profile`

## Tasks
1. CMake skeleton with the targets from the architecture doc: `urbs_core`, `urbs_sim`, `urbs_render`, `urbs_ui`, `urbs`, `urbs_headless`, `urbs_tests`, `bench`.
2. `urbs_core` and `urbs_sim` must not link SDL (CMake check).
3. Window opens, clears to a colour through SDL_GPU, shows the ImGui overlay with FPS.
4. `urbs_headless --version` and `--ticks N` run without a window.
5. CI matrix for macOS arm64, Windows x64, Ubuntu x64.

## Exit
- `cmake --build --preset dev && ctest --preset dev` green on macOS.
- Window opens on macOS. (Windows and Linux are verified by CI once the repo is pushed to GitHub.)

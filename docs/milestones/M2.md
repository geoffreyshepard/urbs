# M2 — Simulation core + performance gate

## Delivered
- `sim::World`: fixed tick (20/s), command queue applied at tick start, seeded RNG streams per system.
- `sim::Scheduler`: timing wheel (4096 slots) + overflow list, fixed node pool, lazy cancellation by token. Due events are sorted by (kind, type, target) and anything past the decision budget spills to the next tick, so results never depend on insertion order.
- Citizens: struct-of-arrays pool with generational ids; lazy needs (base + rate since t0).
- **Agent LOD:** a walking agent costs nothing per tick. Its position is a pure function of (path, start tick, path cumulative times), computed by the renderer only for visible agents; arrival is a scheduled event. Stationary agents only wake at activity end. This covers all three tiers in the sim-design doc with zero per-tick work.
- Pathfinding (`src/path`): nav grid with per-tile costs, 4-connected regions (O(1) unreachable rejection), HPA* over 32×32 chunks (≤ 12 portals per side, exact intra-chunk costs), direct A* for short trips (≤ 64 tiles), full-grid A* fallback, shared ref-counted path store with a (src,dst) cache valid in both directions and invalidated per chunk, async queue with fixed per-tick budget solved on enkiTS workers and merged in request order.
- Service maps: multi-source Dijkstra (Dial buckets) per service, computed incrementally (60k tiles/tick), swapped in when complete.
- Save/load v1: header + zstd payload; round-trips exactly (test: hash equal after 900 more ticks).
- Allocation hook: global operator new counts allocations while `tick()` runs.

## Gate result (M1, release, `stress_50k`: 50k citizens, 500 buildings, 768² map, 3 game days)
- avg 0.09 ms/tick (0.12 ms per frame at 4×), p99 1.0 ms, max 12 ms. Budget: 8 ms / 16 ms. **Pass.**
- 0 allocations inside `tick()`. Path cache hit rate 99%.

## Deviations
- EnTT is not used: buildings and households are plain generational pools too, which keeps saves a straight copy of arrays. (EnTT remains a pinned dependency in case a later system wants it.)
